# adfreegames.app

Static marketing and legal site for the Ad-Free Games iOS app, hosted on GitHub Pages.

- `index.html` – landing page
- `privacy.html`, `terms.html`, `support.html` – legal and support pages
- `styles.css` – shared dark + neon arcade theme (matches the app's ArcadeKit palette)
- `assets/` – app icon and App Store screenshots
- `CNAME` – custom domain

Deployed from the `main` branch root. Edit, commit, push.
